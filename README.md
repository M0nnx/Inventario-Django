# 🛒 Inventario-Django — Sitio Web E-Commerce

Este proyecto es un **sitio web de comercio electrónico** desarrollado con **Python, Django, HTML, CSS y JavaScript**, siguiendo el patrón de diseño **MVT (Modelo-Vista-Template)** propio de Django, inspirado en el patrón MVC.  
Está enfocado en la **gestión de productos** a través de un dashboard personalizado y control de acceso basado en roles.

---

## ⚙️ Tecnologías utilizadas

- **Backend**:
  - Python
  - Django
  - PostgreSQL
- **Frontend**:
  - HTML
  - CSS
  - JavaScript
- **Otros**:
  - Sistema de autenticación por roles
  - Patrón de diseño MVT

---

## 🔐 Funcionalidades principales

### 👥 Sistema de autenticación y roles
- Registro e inicio de sesión
- Control de acceso a vistas protegidas (solo administradores pueden gestionar productos)

### 📦 Gestión de productos (Dashboard)
- CRUD completo sobre productos
- Visualización desde el frontend para usuarios
- Integración con PostgreSQL para almacenamiento de datos

## 🔧 Funcionalidades en desarrollo

- 🛍️ **Carrito de compras**
- 💳 **Integración con sistemas de pago**
