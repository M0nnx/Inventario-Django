# Inventario-Django
Sitio web (E-Commerce) creado utlizando Python, Django, HTML, CSS, Javascript
Siguiendo el patron de diseño MVC(MVT en django porque tiene su propio patron de diseño, es similar al MVC)
El sitio web contiene un sistema de autenticaciones por roles, donde se le da acceso a ciertas vistas solo si es administrador, se comunica en base a varios crud a la base de datos postgresql
